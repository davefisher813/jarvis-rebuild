Text Laws
Every String Has a Role
Page title · eyebrow · section head · row name and meta · urgency · pill · stat tile · day divider · banner · empty state. A string that fits none of these gets restructured, never styled in place. Legal pages and conversation are the only prose surfaces.
Title Case, Everywhere
  • Title Case: page titles, section heads, row names, buttons, chips, sheet titles, tab labels, placeholders that are labels. Small words stay down: a, an, the, to, of, in, with, for.
  • ALL CAPS is rationed: eyebrows, kickers, pills, urgency. Nothing else.
  • Meta stays lowercase: fragments with middle dots · like this one.
  • Conversation is sentence case: onboarding, chat, check-ins, and any question.
  • No sentences in the UI: no period-then-capital in a rendered string. Middle dots divide clauses.
  • No em dashes anywhere.
Everything Actionable Is a Control
  • Copy that names an action IS the button. Directions to a button elsewhere are illegal.
  • Empty states carry their action button, not an address.
  • Counts are pills. Figures are stat tiles. Never prose.

Motion & Enforcement
Motion Rules
  • One spring curve, shared by banners, sheets, and chips.
  • Lists stagger on first paint only, 30ms apart. Tab switches are instant, always.
  • Numbers roll to their new value. Reduced motion snaps.
  • Rows compress under the thumb. Primary buttons carry the red glow.
  • The day ring is a red-orange gradient arc with a soft glow; it bursts at 100%.
  • Completion fires the micro-burst and the native haptic.
The Gate
  • Laws as tests: em dash, short copy, casing on every surface, CSS class existence, versioned keys, typed queries, AI gate, editing primitives. A violation fails the build.
  • Lint gate: rules-of-hooks at error. tsc, vitest, and the production build run on every commit.
  • Preview discipline: visual changes ship 390x844 previews for approval before code.
  • New CSS lands only in the flagged blocks of components.css, citing its approval.
