## 7. Pitfalls this sweep already hit (do not repeat them)

- `--tx-2` and `--tx-3` are the same hex. "Bold grey" is not a distinction.
- **Laws read raw CSS, comments included.** A comment naming `.u-late` above
  a `--sys-red` rule tripped L1. Several laws pin exact CSS text; amend them
  in place with a dated reason, never delete them.
- **Never `rm -rf src/bench`.** It holds three committed benches. Delete only
  the scratch files you created. A scratch bench left behind fails a law.
- **Never build into `dist/` while an audit is serving it**; build to
  `--outDir /tmp/build-check`.
- `pkill -f <pattern>` can kill its own shell (exit 144). Kill by PID.
- Playwright: launch with
  `executablePath: "/opt/pw-browsers/chromium-1194/chrome-linux/chrome"`;
  never `playwright install`. Scripts using playwright must live inside
  `jarvis-app/` to resolve the module.
- The auditor hardcodes port 4173.
- A finding's `fix` text is a suggestion. Several invented one-off classes
  (`fact urgency`, `fact dec-when`); use the primitives in `RULEBOOK.md`.
- Before calling a contrast failure real, check the auditor's layers: on
  2026-09-22 it was counting a 0.5px divider as the ground under every capsule.
- The stop hook wants a clean, pushed tree at the end of every turn.
- A workflow's agents can die on the weekly usage limit mid-run. Read the
  `<failures>` block of the completion notice; a missing reviewer is not a
  clean review. Rerun the lens, do not skip it.
- `triage.py --apply` also writes `handoff.json` (work an agent could not do
  in its own file, and fixes a law blocked) and `dave-queue.json`. Nothing in
  `handoff.json` may be left `done: false` at the end of a phase without a
  stated reason.
